# 출시 체크리스트 (사이즈 어때?)

기준: [비게임 출시 가이드 체크리스트](https://developers-apps-in-toss.toss.im/checklist/app-nongame.md)·[UI/UX 가이드](https://developers-apps-in-toss.toss.im/design/consumer-ux-guide.md)(2026-11-14 확인).
서비스 오픈 정책 페이지(`intro/guide.md`)는 확인 시점에 열리지 않아(Page Not Found) 이전 프로젝트 판단(외부 링크 최소화)을 따랐어요.
콘솔 작업·업로드·검수 요청은 소유자가 직접 해요(계정·약관 동의 필요).

## 1. 체크리스트 대응 (실기기 제외)

"확인" 열: `코드` = 코드로 보장 / `브라우저` = 미리보기에서 확인 / `토스앱` = 실기기에서 확인해야 함.

| 체크리스트 항목 | 대응 | 확인 |
|---|---|---|
| 앱인토스 내비게이션 바 사용, 자체 로고 추가 안 함 | `navigationBar.withBackButton/withHomeButton`, 화면 안 로고는 본문(헤더 아님) | 코드 · 토스앱 |
| 토스 뒤로가기와 자체 뒤로가기 동시 노출 금지 | 토스 안에서는 화면 안 뒤로가기 숨김(`isInToss()`) | 코드 · 토스앱 |
| 최초 화면 뒤로가기 → 종료, 안드로이드 백버튼 | 해시 라우팅·히스토리 기반, 별도 가로채기 없음 | 토스앱 |
| 재접속 시 데이터 유지 | 토스 `Storage`(`sizenote.state.v1`, 사진 별도 키) | 자동 테스트 · 토스앱 |
| SDK 과다·반복 호출 금지 | Storage 읽기는 시작 1회, 쓰기는 사용자 저장 시만, 카메라·앨범은 버튼 1회. 폴링·타이머 없음 | 코드 |
| `eval`·외부 도메인 이동/임베드 금지 | 없음(`eval`, `location.replace`, `iframe`, `window.open` 미사용). 참고 주소는 저장만 하고 열지 않음 | 코드 |
| SSR 금지 / HTTPS·wss | CSR(Vite 정적 번들), 네트워크 통신 없음 | 코드 |
| 핀치줌 비활성 | viewport `maximum-scale=1, user-scalable=no`. 사진 측정 확대는 화면 안 1x~3x 버튼 | 코드 |
| 라이트 모드만 | `color-scheme: light`, 다크 스타일 없음 | 코드 |
| 2초 이상 지연 없음 | 첫 화면은 로컬 데이터만, 번들 gzip 약 150KB | 토스앱(측정) |
| 기기 권한은 동의 먼저, 거부해도 나머지 동작 | camera·photos만 선언, 버튼 누를 때 SDK 권한 흐름으로 1회. 거부 시 안내 토스트 + 직접 입력 | 코드 · 토스앱 |
| 진입 직후 바텀시트·강제 유도 없음 | 바텀시트 없음, 첫 화면은 홈 | 브라우저 |
| 모든 화면에서 나갈 수 있음 / CTA로 결과 예측 가능 | 토스 내비게이션 바 + 버튼 문구는 동작 그대로(‘저장하기’, ‘비교하기’, ‘측정값 넣기’) | 브라우저 |
| 자사 서비스·앱 설치 유도, 광고 없음 | 없음 | 코드 |
| 비속어·위법 콘텐츠 없음, 해요체 | 전 문구 해요체, ‘~되어요’·‘습니다’ 없음 | 코드 |
| 다이얼로그 왼쪽 버튼 ‘닫기’ | `overlay.tsx` 기본값 ‘닫기’ | 브라우저 |
| 오류가 아닌 상황에 느낌표 아이콘 금지 | ‘추가 확인 필요’는 물음표, 주의 안내는 i 아이콘. 느낌표는 ‘찾을 수 없음’·계산 실패에만 | 코드 |
| 탭바는 플로팅 형태, 2~5개, 토스 하단 탭과 겹치지 않게 | 홈·비교·설정 3개, 양옆·아래 띄운 둥근 플로팅 | 브라우저 |
| 360px에서 가로 스크롤 없음(관례) | 19개 화면 + 비교 결과 + 사진 측정 scrollWidth = 360 | 브라우저(2026-11-14) |
| 브랜드 로고 600×600 각진 정사각, 배경 있음 | `assets/brand/console-icon-600.png`(크림 배경 꽉 참). 토스 그래픽 미사용 | 코드 |
| 브랜드 이름 한글 | ‘사이즈 어때?’ | 콘솔 |
| 토스 로그인·인앱 결제·토스페이·광고 | 사용 안 함(해당 항목 제외) | — |
| 화면 렌더 오류 대비 | ErrorBoundary가 흰 화면 대신 ‘처음 화면으로’ 안내 | 코드 |

## 4. 실기기 확인 (README 상태표에 기록)

- [ ] 첫 진입 시 권한 팝업·바텀시트가 뜨지 않는다
- [ ] 공간 → 측정 → 저장 → 미니앱 완전 종료 후 재진입 시 기록 유지
- [ ] 사진 찍기 / 앨범에서: 허용 → 저장 → 재진입 시 사진 표시, 거부 → 안내 후 직접 입력 가능
- [ ] 측정 편집 중 사진 추가 후 저장하지 않고 나가면 사진이 남지 않음
- [ ] 사진 보조 측정: 줄자 대비 오차 기록(같은 평면·정면 / 비스듬한 촬영)
- [ ] 토스 뒤로가기·홈·안드로이드 백버튼, 최초 화면 뒤로가기 종료
- [ ] Safe Area(노치·홈 인디케이터)와 플로팅 탭바·하단 버튼 겹침 없음, 숫자 키패드가 입력칸을 가리지 않음
- [ ] 비교 → 기록 저장 → 기록 상세, 모든 데이터 삭제 후 다른 데이터 영향 없음
- [ ] 더보기(⋯) 공통 기능(신고·공유) 동작
